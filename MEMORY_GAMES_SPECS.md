# Matching Games Category Specifications

This document outlines the specifications for the "Matching Games" category within the CogniBoost application. These games are designed to enhance cognitive skills primarily related to memory, recognition, and concentration.

## 1. Memory Matrix

*   **Game Name:** Memory Matrix
*   **Core Concept:** Players are briefly shown a grid of items (e.g., icons, shapes, colors). The items then disappear or are hidden, and the player must recall their locations or recreate the pattern.
*   **Cognitive Skills Targeted:**
    *   Primary: Recall, Working Memory, Visual-Spatial Recall.
    *   Secondary: Concentration, Short-Term Memory.
*   **Gameplay Mechanics:**
    *   A grid (e.g., 3x3, 4x4, 5x5) is displayed.
    *   A set of items or a pattern appears in some cells for a short duration.
    *   Items are then hidden (e.g., flipped over, blanked out).
    *   The player must click on the cells where they remember the items being located, or select the correct items for the highlighted cells.
    *   Items could be simple icons, geometric shapes, colors, or numbers.
*   **Customizable Difficulty:**
    *   Grid size (e.g., 2x2 up to 6x6 or larger).
    *   Number of items to remember.
    *   Presentation time of items (shorter for harder levels).
    *   Complexity/similarity of items.
    *   Time limit to recall.
    *   Introduction of distractors or requiring sequence recall.
*   **Success Metrics:**
    *   Accuracy of recalled locations/items.
    *   Time taken to complete the recall.
    *   Number of errors or incorrect attempts.
    *   Level achieved based on increasing difficulty.

## 3. Tidal Treasures (Conceptual - Requires more specific design)

*   **Game Name:** Tidal Treasures
*   **Core Concept:** This game might involve finding matching pairs of items hidden among a larger set, possibly with a "tidal" or "ocean" theme where items are revealed and hidden, or shift position. *Assuming a pair-matching theme with dynamic elements.*
*   **Cognitive Skills Targeted:**
    *   Primary: Recall, Recognition, Working Memory.
    *   Secondary: Concentration, Visual Search, Attention.
*   **Gameplay Mechanics:**
    *   A collection of items (e.g., shells, sea creatures, treasure chests) are displayed, typically face down or obscured.

    *   If a pair is found, they are removed or marked as matched. If not, items are hidden again.
    *   The "tidal" aspect could mean items slowly disappear and reappear, or their positions subtly shift after a certain number of turns or time, adding a dynamic challenge.
*   **Customizable Difficulty:**

*   **Success Metrics:**
    *   Time to find all pairs.
    *   Number of incorrect attempts (mismatches).

    *   Efficiency (e.g., pairs found per move).

## 5. Visual Memory Matching Game (General Template)

*   **Game Name:** Visual Memory Match (or specific themed name, e.g., "Shape Match," "Icon Find")
*   **Core Concept:** Players are presented with a set of items (e.g., cards, tiles) face down. They turn over items two at a time, trying to find matching pairs.
*   **Cognitive Skills Targeted:**
    *   Primary: Recall, Recognition, Working Memory.
    *   Secondary: Concentration, Visual Discrimination.
*   **Gameplay Mechanics:**
    *   A grid or array of items is presented face down.
    *   Player selects two items per turn.
    *   If the items match, they remain face up or are removed.
    *   If they don't match, they are turned face down again after a brief viewing period.
    *   The game continues until all pairs are found.
    *   Items can be images, symbols, words, colors, patterns, etc.
*   **Customizable Difficulty:**
    *   Grid size (number of items, e.g., 2x2, 4x4, 6x5).
    *   Similarity of the items (e.g., subtle differences in shapes, shades of colors).
    *   Time limit for finding all pairs or for each move.
    *   Number of items to match (e.g., pairs, triplets).
    *   Briefly showing all items at the start (or not).
*   **Success Metrics:**
    *   Time to complete the game.
    *   Number of moves or attempts made.
    *   Number of errors (mismatches).
    *   A score derived from time and accuracy.

# Sequencing/Recall Games Category Specifications

## 1. Category Name
Sequencing/Recall Games

## 2. Core Concept
This category includes games that challenge players to memorize and accurately recall sequences of items. These items can be auditory (sounds, spoken words, melodies), visual (colors, shapes, numbers, patterns), or actions. The core task is to reproduce the sequence as presented.

## 3. Cognitive Skills Targeted
*   **Primary:** Short-term Memory, Working Memory, Sequential Processing, Auditory Memory (for sound-based games), Visual Memory (for visual-based games).
*   **Secondary:** Attention, Concentration, Focus.

## 4. General Gameplay Mechanics
*   **Presentation:** The game presents a sequence of items to the player. This could be one item at a time, or the full sequence shown briefly.
*   **Recall/Replication:** After the presentation, the player attempts to replicate the sequence. Input methods will vary based on the item type (e.g., clicking colored buttons, typing numbers, playing notes on a virtual keyboard, selecting items in order).
*   **Feedback:** The game provides feedback on the accuracy of the player's recall. This could be immediate (after each item in the sequence) or at the end of the attempt.
*   **Progression:** Typically, if the player successfully recalls a sequence, the next sequence will be longer or more complex.

## 5. Examples of Variations
*   **Number Sequence Recall (e.g., "Digit Span"):** Players see or hear a sequence of digits and must type them in the correct order.
*   **Color Sequence Game (e.g., "Simon Says" variant):** A series of colors flash in sequence, and the player must click colored pads in the same order.
*   **Sound/Melody Recall:** Players hear a short melody or a sequence of distinct sounds and must replicate it using on-screen controls (e.g., a small piano interface, buttons corresponding to sounds).
*   **Pattern Recreation (Visual):** A pattern is drawn on a grid or a series of locations light up, and the player must recreate the pattern or sequence of locations.
*   **Action Sequence (e.g., "Follow the Leader"):** A character or avatar performs a sequence of actions, and the player must command their avatar to do the same.

## 6. Customizable Difficulty
*   **Length of Sequence:** Increasing the number of items in the sequence (e.g., starting with 3 items and increasing).
*   **Speed of Presentation:** Presenting items more quickly.
*   **Complexity of Items:**
    *   For numbers: Using a wider range of digits, or larger numbers.
    *   For colors: Using more colors, or shades that are harder to distinguish.
    *   For sounds: Using more notes, or sounds that are less distinct.
    *   For patterns: More complex or less symmetrical patterns.
*   **Time Limit:** Introducing a time limit for recall.
*   **Distractors:** Adding a delay or a distracting task between the presentation of the sequence and the recall phase.
*   **Modality:** Requiring recall across different modalities (e.g., see a visual sequence, recall by auditory cues).
*   **Reverse Recall:** Requiring the player to recall the sequence in reverse order.

## 7. Success Metrics
*   **Maximum Sequence Length Correctly Recalled:** The highest number of items in a sequence the player can reliably remember and reproduce.
*   **Number of Errors:** Total incorrect items or order mistakes within a session or per sequence.
*   **Speed of Recall:** Time taken to input the recalled sequence.
*   **Accuracy Percentage:** (Correct items / Total items) * 100.
*   **Levels Completed:** Number of progressively harder sequences or stages cleared.
*   **Score:** A composite score potentially based on sequence length, accuracy, and speed.
